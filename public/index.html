plot

An engineering drawing sheet. Zoned border, crop marks, a title block, and values drawn as dimension lines. Hover for the grid zone, drag a dimension to resize it.

stub

A perforated ticket. The tear line splits off a numbered stub. Click a hole to punch it, drag across a row to punch it, click the stub to tear it off.

tui

A terminal monitor panel. Hotkey number in the title, key hints on the bottom edge, a live braille trace. Focus a panel, then use j and k, or space to pause.

themes

Ten palettes. Set one on any element with data-fr-theme, or leave it off to follow the system: paper in light, ultraviolet in dark.

use

No build step and no framework. Every figure renders with the stylesheet alone; the script adds the live parts.

  1. Add the stylesheet. The three faces load from next to it, and only the ones a page uses.

    <link rel="stylesheet" href="frames.css">

  2. Add the script for dragging, punching, zone readouts and live graphs.

    <script type="module" src="frames.js"></script>

  3. Copy any figure above with its copy html button and paste it in.

  4. Pick a theme with data-fr-theme="ultraviolet". Freeze motion with data-fr-static. Both work on any ancestor.
